# Multi-Factor Authentication (MFA) Implementation Evidence

## Implementation Overview
This repository contains active validation evidence for the Avant-Tap Enterprise Identity and Access Management (IAM) MFA rollout. The simulation demonstrates functional end-to-end Time-based One-Time Password (TOTP) enforcement.

## Verification Artifacts & Test Walkthrough

### 1. Primary Authentication
* **Artifact:** `01-Primary-Login.jpg`
* **Validation:** User submits valid primary credentials at the enterprise login screen.

### 2. Authenticator Enrollment
* **Artifact:** `02-TOTP-Enrollment-QR.jpg`
* **Validation:** System generates a localized QR code provisioned with a secure base32 secret key for authenticator app binding.

### 3. Verification Challenge (Timer Window Start)
* **Artifact:** `-MFA-Token-Verification-Start.jpg`
* **Validation:** User inputs the live 6-digit TOTP code generated by the authenticator app at the beginning of the 30-second token validity window.

### 4. Verification Challenge (Timer Window End)
* **Artifact:** `MFA-Token-Verification-End.jpg`
* **Validation:** Token acceptance testing verified near the expiration of the 30-second TOTP window to confirm strict time drift adherence.

### 5. Access Granted
* **Artifact:** `05-MFA-Access-Granted.jpg`
* **Validation:** Successful multi-factor verification grants session access to the secure enterprise dashboard.
